## 0.1.0.dev10 — local development preview

The first preview is a paper companion and diagnostic toolkit. It supplies
method code and runnable authored examples; it does not certify paper numerical
reproduction. No remote publication has been performed.

- Pass@(K,T), exact deterministic grid budget certificates and slack reports.
- Matched/Base-monitor frozen pools, fixed-state quality, controlled error
  interventions and continuation recovery with raw replay audits.
- Checkpoint dual validation, portable dynamics reports and offline W&B hooks.
- BudgetMix occurrence sampling, audited plans and pinned trainer integration.
- Raw teacher-forced NLL/action masks, aligned policy LLR and explicit trajectory
  length controls that exclude incompletely scored supplied trajectories.
- Explicit oracle/judge process mixing, content-addressed judge cache and
  train-only native reward placement. Two real 1.7B one-rank updates passed
  [independent GPU verification](docs/verification/process-gpu.md).
- Public external scorer adapter, one-command CPU walkthrough, authored reports,
  four tool tutorials, optional HF integration and dependency-free installed core.
- Source/wheel payload inspection, document-link and version checks.

Known limits: BFCL/SQL/Terminal are external inputs; coding is a derived bounded
checker. PPO/GiGPO, multi-rank and resume remain deferred. Historical seeded
trainer off/on divergence remains visible. Citation authors, paper link and
external publication destination are awaiting confirmation.
