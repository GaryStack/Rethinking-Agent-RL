# Authored static reports

All files here are synthetic fixtures, not paper or neural-model results.
`tight-budget.html` executes the scripted offline demo; `likelihood.html` uses
explicit authored token logprobs. `dynamics.html` and `error-prefix.html` illustrate
metric-only synthetic series, without a raw model audit. `budgetmix.json` is a
sampler/group audit, not rollout evidence. `process-signal.json` is reward mixing;
use `examples/process_signal_training.py` for the actual synthetic optimizer path.
